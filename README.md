# CS-370 Pirate Intelligent Agent

## Project Overview

This project was developed for CS-370: Current and Emerging Trends in Computer Science at Southern New Hampshire University. The objective was to create an intelligent pirate agent capable of navigating a maze and finding treasure using deep Q-learning and neural networks.

## Project Reflection

### What code were you given, and what code did you create yourself?

For this project, I was provided with starter code that included the maze environment, experience replay functionality, and a neural network model.
The TreasureMaze.py file defined the environment and supported the pirate's movements, while GameExperience.py managed the agent's stored experiences.
My responsibility was to complete the Q-training algorithm within the Jupyter Notebook. I implemented the training process, including exploration and exploitation,
experience replay, and neural network updates. After training, the agent achieved a 100% win rate at epoch 174 and successfully completed the verification test.

### How do I approach a problem as a computer scientist?

I approach problems by first identifying the goal, understanding the requirements, and breaking the problem into smaller steps. I then evaluate possible solutions,
implement an appropriate algorithm, and test the results to identify errors or areas for improvement. During this project, I followed this process by reviewing the starter code,
implementing the training algorithm, testing the agent's performance, and adjusting its learning process. This experience reinforced the importance of testing, debugging, and evaluating results when developing software.

### What are my ethical responsibilities to the end user and the organization?

As a computer scientist, I have a responsibility to develop systems that are reliable, secure, and designed with the user's needs in mind. This includes protecting sensitive information, testing software to reduce errors,
and being transparent about system limitations. When working with artificial intelligence, it is also important to consider how inaccurate predictions or unexpected behavior could affect users and organizations.
